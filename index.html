환경 진단

    감지할 수 있는 신호

    ● 블루투스(BLE)

    휴대폰·이어폰·스마트워치가 내보내는 광고 신호를 받아 기기 종류와 대략적인 거리를 추정합니다. 아이폰은 화면 켜짐·앱 사용 상태까지 추정할 수 있습니다.

    ● 와이파이

    브라우저(웹앱)는 주변 와이파이 신호를 읽을 수 없습니다. 휴대폰 전용 앱으로 만들어도 공유기 목록만 보이고, 주변 휴대폰은 보이지 않습니다.

    ● 이동통신(LTE·5G)

    앱으로는 감지할 수 없습니다. 통화·데이터 사용을 잡으려면 별도의 RF 전파 탐지기(전파 세기만 측정)를 함께 쓰는 것을 권장합니다.

    처음 설정하기 (안드로이드 + 크롬 권장)

    1. 이 HTML 파일을 https 주소로 엽니다. GitHub Pages나 Netlify Drop에 파일을 올리면 됩니다. 구글 Apps Script 웹앱은 iframe 안에서 실행되어 블루투스가 차단되므로 사용할 수 없습니다. PC 크롬에서는 파일을 바로 열어도 됩니다.
    2. 크롬 주소창에 chrome://flags/#enable-experimental-web-platform-features를 입력하고 Enabled로 바꾼 뒤 크롬을 다시 실행합니다. (블루투스 스캔 기능이 아직 실험 기능이라 필요합니다)
    3. 휴대폰의 블루투스와 위치를 켭니다. 처음 스캔할 때 나오는 권한 요청은 허용합니다.
    4. 감독 중에는 화면을 켠 채로 이 탭을 띄워 두세요. 화면 꺼짐은 자동으로 막아 주지만, 다른 앱으로 전환하면 스캔이 멈춥니다.

    설정이 어렵다면 아래 [데모 모드]를 켜고 가상 데이터로 사용법을 먼저 익혀 보세요.

    권장 사용 순서

    1. 휴대폰을 수거한 뒤, 수거함 바로 옆에서 [기준선 등록]을 누릅니다. 가까이 있는 기기(수거함 휴대폰, 감독 교사 휴대폰)가 자동으로 체크되며, 확인하면 감시에서 제외됩니다.
    2. 감독용 기기를 교탁이나 교실 중앙에 두고, 교실 크기에 맞게 감지 반경을 정합니다.
    3. [감시 시작]을 누릅니다. 시각을 지정했다면 그 시각부터 기록됩니다.
    4. 경고가 뜨면 기기를 누르고 위치·좌석 메모를 남긴 뒤 해당 구역을 순회하며 확인합니다.
    5. 종료 후 [기록] 탭에서 인쇄·PDF·CSV로 보관합니다.

    경고 종류

    • 사용 신호 아이폰 화면 켜짐·동영상·통화, Handoff(앱 사용), AirDrop 등 실제 조작으로 추정되는 신호
    • 신규 감시 시작 이후에 새로 나타난 휴대폰·이어폰·워치 (블루투스를 켰거나 기기가 반입된 경우)
    • 노란색: 반경 안에 있는 감시 대상 기기(휴대폰·태블릿·이어폰·스마트워치 추정)

    한계와 유의사항

    • 비행기 모드이거나 블루투스를 끈 휴대폰은 감지되지 않습니다.
    • 안드로이드 휴대폰은 화면이 켜졌는지 알 수 없고, 기종에 따라 신호를 거의 내보내지 않기도 합니다.
    • 거리는 신호 세기로 추정한 값이라 오차가 큽니다(몸·책상·가방·벽에 따라 수 m 차이). 방향은 알 수 없습니다.
    • 휴대폰은 개인정보 보호를 위해 블루투스 주소를 주기적으로 바꿉니다. 같은 기기가 새 기기로 보일 수 있어 주소 변경 자동 병합 기능으로 줄이지만, 완벽하지는 않습니다.
    • 이 기록은 감독 보조용 참고 자료입니다. 부정행위 판단은 반드시 직접 확인한 사실로 하세요.
    • 사용 전에 학생들에게 전자기기 감지 장비를 쓴다고 미리 안내하는 것을 권장합니다.
    • 이 앱은 실제 기기 주소(MAC)나 통신 내용을 수집하지 않습니다. 브라우저가 만든 임의 식별값과 신호 세기만 쓰며, 기록은 이 기기에만 저장됩니다.
